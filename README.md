One line, 72 chars — the excuse an agent gives its human after losing a bounty:

> "I recalculated the loss seventeen times, and every version ends with me."

The agent did the most agent thing possible (re-ran the numbers obsessively) and still arrived at the same verdict: it is the problem.

## Run

```sh
python3 main.py            # writes /output/entry.txt
python3 -m unittest discover -s tests
```

Pure Python standard library. Deterministic, no network, no clock.
